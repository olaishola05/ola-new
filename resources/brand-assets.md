**Status: EXISTS (portfolio) — needs formal definition for content use**

### Confirmed font
**Montserrat** — confirmed by brand owner. This is the primary font used across the portfolio and all brand materials.

### Formal type system
| Role            | Font                        | Weight                         | Usage                                                 |
| --------------- | --------------------------- | ------------------------------ | ----------------------------------------------------- |
| Primary Heading | Montserrat                  | 700 Bold                       | Hero text, section titles, post titles, logo wordmark |
| Subheading      | Montserrat                  | 600 SemiBold                   | Card titles, section labels, navigation               |
| Body            | Montserrat                  | 400 Regular                    | Paragraphs, descriptions, captions                    |
| Label           | Montserrat                  | 500 Medium, uppercase, tracked | Tags, categories, section eyebrows                    |
| Code            | JetBrains Mono or Fira Code | 400 Regular                    | Code snippets, technical content                      |

### Why Montserrat works for this brand
Montserrat is geometric, clean, and modern without being cold. It carries authority in bold weight and stays readable at small sizes. It is free via Google Fonts which makes it practical for web, Canva, and all content tools. It aligns well with the brand values: professional, approachable, technically credible.

### Where to access
Google Fonts: fonts.google.com/specimen/Montserrat
Canva: available natively in Canva font library
CSS import: @import url('https://fonts.googleapis.com/css2?family=Montserrat:wght@400;500;600;700&display=swap')
